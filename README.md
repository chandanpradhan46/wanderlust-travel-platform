   # Wanderlust 🌍
   A full stack travel listing & booking platform.

   🔗 **Live demo:** https://wanderlust-demo-app.onrender.com/listings

   > ⏳ Hosted on Render's free tier, so the first load may take up to a minute.

   ## Features
   - Browse, create, edit and delete listings
   - User signup and login
   - Reviews and ratings
   - Image uploads
   - Map integration

   ## Tech Stack
   Node.js, Express, MongoDB, EJS, Bootstrap

   ## Run locally
   git clone https://github.com/chandanpradhan46/wanderlust-travel-platform.git
   cd wanderlust-travel-platform
   npm install
   node app.js
